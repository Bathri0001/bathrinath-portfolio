PROJECT OUTPUT SCREENSHOTS
Drop your screenshots (png / jpg / jpeg / webp) into these folders. They appear automatically,
in filename order, in the "View Outputs" tabs and inside the 3D device on each project card.
Name them 1.png, 2.png, 3.png ... to control the order.

  ONGC/       ONGC Document Intelligence System   (PC frame)
  TF/         Trend Fusion                        (PC frame)
  Dine-mate/  Personalized Food Recommendation    (PC frame)
  UFAS/       University Finance Administration   (PC frame)
  PTU/        PTU IQAC App                        (Phone frame)
  IQ/         Adaptive IQ Predictor               (Phone frame)

Then run: npm run dev  (or redeploy on Vercel).
